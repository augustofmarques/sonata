# Material 3 Reference

**Role in Sonata:** Expression reference.

Material 3 is used selectively. Sonata is interested primarily in the systems behind the visual language rather than adopting Material component conventions wholesale.

Selected areas:

- color roles and tonal relationships
- source-color-driven theming
- dynamic color
- expressive hierarchy
- typography systems
- motion and continuity
- shape as a visual language
- adaptive composition

Material's color architecture is especially relevant because it separates source color, tonal palettes and semantic color roles while using accessibility and visual expression as constraints. [Material Color Utilities](https://github.com/material-foundation/material-color-utilities/blob/main/concepts/dynamic_color_scheme.md)

Sonata intentionally does not require:

- Material navigation patterns
- Material component look-and-feel
- Material-specific terminology everywhere
- Material's default geometry
- Material as product identity
