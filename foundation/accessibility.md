# Foundation — Accessibility

Accessibility is a cross-cutting invariant of Sonata.

It governs:

- contrast and readability
- focus visibility
- keyboard access
- target size
- text scaling
- semantic labeling
- assistive technology compatibility
- reduced motion
- reduced transparency
- meaningful state communication

Accessibility constraints override aesthetic customization.

User preferences may change expression, but they must not disable required semantics or make essential functionality inaccessible.
