# Implementation — Sonata Skill

This file is intentionally skeletal until the Sonata specification is sufficiently mature.

The future skill should:

1. identify the applicable Foundation rules;
2. establish the semantic structure;
3. select System primitives/components;
4. apply Expression rules;
5. select Mobile/Adaptive/Desktop composition;
6. apply relevant Patterns;
7. expose appropriate customization;
8. validate accessibility, localization and consistency.

The skill should reference the other Sonata documents instead of duplicating them wholesale.
