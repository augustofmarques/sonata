# Adaptive — Overview

Sonata is adaptive rather than merely responsive.

The same semantic product may change layout, density, navigation, information visibility and interaction technique as the available environment changes.

## Classes

- Mobile Class — touch-first, focused-context composition.
- Adaptive Class — transitional compositions for intermediate or changing environments.
- Desktop Class — pointer/keyboard-first, simultaneous-context composition.

## Width heuristics

Initial conceptual classes may use:

- Compact: < 600
- Medium: 600–839
- Expanded: 840–1199
- Large: 1200–1599
- Extra Large: ≥ 1600

These are reference ranges, not device identities. Platform units may differ.

## Adaptation modes

- Reflow
- Reveal
- Collapse
- Substitute
- Split
- Merge

Width is not the only signal; input modality and platform capabilities matter.
