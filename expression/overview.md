# Expression — Overview

Expression defines how the interface communicates visually and experientially.

Primary domains:

- color
- typography
- shape
- surface and depth
- spacing
- density
- motion
- animation
- visual emphasis
- hero composition
- iconography

## Material reference

Sonata uses **Material 3 Expressive** as the primary external reference for expressive visual principles (D-172), refining the general Expression-authority decision (D-004).

Material 3 Expressive informs:

- color
- typography
- shape
- motion
- animation
- visual emphasis
- expressive composition
- hero moments
- personalization

Sonata does not inherit Material's complete component taxonomy or UX conventions.

Material 3 Expressive is a source of expressive techniques, not a second Foundation. See [Material 3 Expressive reference](../references/material-expressive.md) and [Apple HIG](../references/apple-hig.md) as an additional secondary reference (D-173).
