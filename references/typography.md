# Typography References

## Red Hat

The Red Hat Design System uses three related families:

- Red Hat Display — headings and expressive display use.
- Red Hat Text — body and smaller text.
- Red Hat Mono — code and technical text.

Its typography token system also defines locale-specific Noto fallbacks for scripts including Arabic, Hebrew, Japanese, Korean, Malayalam, Thai, Simplified Chinese and Traditional Chinese. [Red Hat font family](https://ux.redhat.com/foundations/typography/font-family/) [Typography tokens](https://ux.redhat.com/tokens/font/)

Sonata adopts this architecture as its recommended default, not as a mandatory typeface.

## Implication for Sonata

Typeface choice is replaceable; the semantic type architecture is not.

Sonata must maintain explicit roles for UI/text, display, mono/code and numeric data even when several roles share one family.
