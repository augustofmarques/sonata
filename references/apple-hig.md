# Reference — Apple Human Interface Guidelines

**Role in Sonata:** Secondary reference (D-173). See the [Reference Authority model](../governance/authority-matrix.md) (D-192) for how this classification works generally. These references supplement rather than override GNOME HIG.

## Role in Sonata

Apple Human Interface Guidelines are a secondary reference for:

- platform-aware interaction
- adaptive navigation
- toolbars
- sidebars
- sheets
- popovers
- material surfaces
- spatial continuity
- window/application composition
- visual polish

Apple guidance does not override GNOME HIG within Sonata's Foundation.

## Primary use

Apple is particularly relevant to Sonata's Expression and adaptive/system layers where its current platform design demonstrates effective treatments for:

- floating sidebars
- translucent surfaces
- contextual toolbars
- adaptive navigation
- multi-window composition
- platform-aware overlays

## Non-adoption

Sonata does not become an Apple-style design system.

Apple-specific:

- terminology
- APIs
- platform constraints
- iconography
- branding
- platform-exclusive conventions

remain reference material unless explicitly adopted by Sonata.

## Current visual relevance

Apple's current platform design uses translucent, dynamic material treatment across elements such as bars, search fields, alerts, popovers and split views, and provides APIs for custom components using similar material behavior.

This makes Apple a useful reference for Sonata's surface/material expression — see [`../expression/surface-depth.md`](../expression/surface-depth.md) and [`../system/overlays.md`](../system/overlays.md) (D-154).
