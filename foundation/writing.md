# Foundation — Writing Style

Writing is part of Sonata's Foundation.

The existing GNOME HIG writing guidance remains authoritative for product language. Sonata does not replace it with a visual-language rule.

## Scope

Applies to:

- labels
- headings
- buttons
- menus
- dialogs
- errors
- empty states
- helper text
- notifications
- confirmations
- onboarding
- system feedback

## Sonata rule

Visual expression must not make product language less clear, direct or semantically consistent.

A more expressive interface does not justify:

- vague action labels
- decorative marketing language in functional UI
- unnecessary jargon
- inconsistent terminology
- text inflation that obscures the task

Locale-specific writing may adapt idiomatically while preserving the same semantic principles.
