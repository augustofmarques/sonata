# Adaptive — Desktop Class

Desktop Class prioritizes:

- pointer
- keyboard
- higher information density
- simultaneous contexts
- persistent navigation where useful
- multi-pane layouts
- contextual toolbars
- power-user workflows

Desktop may use compact and dense modes when the workflow benefits from information efficiency.

## Multi-pane examples

- Navigation | Content
- Navigation | Content | Inspector
- Master | Detail
- Master | Detail | Properties
