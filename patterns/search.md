# Pattern — Search

Search is appropriate when retrieval is a meaningful task.

Possible scopes:

- application
- page
- collection
- context
- command

Search should preserve normal content discoverability rather than becoming the only way to access information.

A unified, global search/command surface is intentionally scarce (see [Global command/search surface restraint](command-palette.md#global-commandsearch-surface-restraint)); ordinary contextual search fields are not subject to that constraint.
