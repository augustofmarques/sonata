# Pattern — Power User Workflows

Sonata permits advanced controls when the application's complexity justifies them.

Potential capabilities:

- command palette
- keyboard shortcuts
- advanced search
- filtering
- bulk operations
- configurable toolbars
- multi-selection
- inspector panels
- workspaces

Power features should augment, not replace, baseline usability.

## Workspaces

Workspace is an official Sonata concept (D-060). A workspace may represent a project, a task context, a user workflow, a document set, a tool configuration, a saved arrangement, or a temporary working environment. It may contain navigation state, open documents, visible/arranged panels, selected tools, context and user configuration. Workspaces are especially valuable in complex professional software.

When appropriate, applications may let users (D-061):

- create workspaces
- rename workspaces
- save workspaces
- restore workspaces
- switch workspaces
- configure visible tools
- reorder tools
- hide tools
- pin tools
- restore defaults

Applications determine which capabilities are exposed — capability is global, exposure is contextual (Principle 9, D-017).
