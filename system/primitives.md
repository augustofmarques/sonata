# System — Primitives

Radix is the conceptual and implementation reference for the System layer.

Primitives provide low-level interaction behavior and accessibility infrastructure.

Examples include:

- Dialog
- Popover
- Dropdown Menu
- Tabs
- Accordion
- Tooltip
- Select
- Checkbox
- Radio Group
- Slider

Sonata should prefer primitives that can be composed and restyled rather than treating a fixed visual component appearance as authoritative.
