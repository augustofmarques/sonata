# Customization — Color

Users may receive:

1. curated Sonata-safe accent choices;
2. an advanced custom color input;
3. a neutral-palette identity choice, where the application exposes it.

A source color is transformed into a usable semantic palette rather than directly replacing every component color — see [`../expression/color.md`](../expression/color.md) for the generation pipeline and semantic roles this feeds.

The application may restrict choices, provide its own palette or allow arbitrary input. Semantic status colors (success/warning/danger/info) are never user-remappable — see [Principles](../governance/principles.md).
