# Material Expressive Reference

**Role in Sonata:** Primary Expression reference (D-172), refining the general Expression-authority decision (D-004).

Material 3 Expressive is the primary external reference for Sonata's Expression layer — the layer's other reference, generic Material 3 (`material.md`), remains a supporting reference specifically for the underlying color/tonal systems Material 3 Expressive builds on.

Material 3 Expressive informs:

- color
- typography
- shape
- motion
- animation
- visual emphasis
- expressive composition
- hero moments
- personalization

Material Expressive is particularly relevant to Sonata's interest in stronger visual hierarchy and intentional emphasis.

Sonata may borrow the principle that a primary action can receive much greater visual prominence while remaining in the same structural location. The implementation should preserve the Foundation's layout and semantics while allowing Expression to control salience through size, contrast, color, shape and motion.

Sonata therefore treats expressive emphasis as a functional design tool rather than as mandatory decoration.

Sonata does not inherit Material's complete component taxonomy or UX conventions — see [Expression Overview](../expression/overview.md).

Source: Google Material Design documentation and current Material Expressive guidance.
